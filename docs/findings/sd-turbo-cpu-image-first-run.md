# What was measured

One image generated by `stabilityai/sd-turbo` via the `diffusers` library on CPU. 8 inference steps, 512×512 output. Energy measured at the wall via a Tapo P110 plug at 1 Hz polling, with the same focus-mode + lock-file protocol every OWL measurement uses.

# Numbers, from the stored result

- `delta_e_wh`: 0.2099 Wh
- Inference steps: 8
- Output size: 512 × 512
- Confidence: 🟢 under the CR-028 Phase 2 CI model
- Backend: AMD Ryzen 9 7900, CPU path

# What this measurement does not establish

- It does not compare CPU and GPU energy on the same model. SDXL-Turbo and the GPU paths are separate stored runs.
- It does not measure image quality. SD-Turbo's native 1–4 step output is a separate question.
- It does not generalise across content. Single prompt, single run — variance across prompts is not characterised here.
